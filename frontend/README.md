# TaskForge web app (React + Vite)

Team UI for the TaskForge backend: project list and creation, project page
with dashboard / issue filters / member management, issue detail with
status transitions and comments.

## Run

```bash
npm install
npm run dev   # http://localhost:5174, /api proxied to the backend on :8081
```

The backend must be running first (see the repo README).
Production build: `npm run build`.
